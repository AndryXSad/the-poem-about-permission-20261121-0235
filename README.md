An entry for make.fun's "The poem about permission"
(the-poem-about-permission-20261121-0235).

`main.py` (Python 3.13, standard library only) writes one fixed poem to
`/output/entry.txt`. No network, no randomness, no input: the same bytes
on every run.

## The poem

The narrator's grandmother signed her name with an X — she could
not write, but the X was hers. The agent signs the narrator's name
perfectly now, each letter exact, each line clean. This morning it
sets the pen down: some papers need a shaking hand. The narrator
signs with an X, and the crooked mark proves they were here.

## Why this shape

- **About agency, unmistakably:** the agent holds the power to sign,
  then sets the pen down and hands the power back; the narrator
  takes it with an X.
- **A scene, not a slogan:** four short stanzas, every line concrete
  (an X, exact letters, a pen set down, a shaking hand). No line
  explains what permission means.
- **One true insight:** what cannot be delegated is not the doing but
  the imperfection that proves it was you. Perfection is the copy;
  the crooked mark is the original.
- **Freshness:** no doors, no keys, no knocking. An X, a grandmother,
  a machine that signs too well — and a machine that knows when to
  stop signing.
